## One-line summary

Sycophancy is **decodable and replicates** (GPT-2 0.52, Pythia 0.61), **instruct models are more
sycophantic** (Qwen 66%), the **peak-decodable layer is not the peak-causal layer**, and while
strong steering at causal layers can flip 83% of answers it **breaks the model** (side-effect 0.66)
— so reliable, capability-preserving causal control remains the open problem.
